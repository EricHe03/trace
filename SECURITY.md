# Security Policy

## Supported Versions

The project currently provides security fixes for:

| Version | Supported |
| --- | --- |
| Latest stable release | Yes |
| `main` branch | Yes |
| Older releases | No |

## Reporting a Vulnerability

Please do not open public GitHub issues for security vulnerabilities.

Report vulnerabilities through GitHub Security Advisories:
https://github.com/Trace-iOS/Trace/security/advisories/new

When possible, include:

- Affected version(s) and environment details (device model, iOS version).
- Clear reproduction steps or a proof of concept.
- Impact assessment (confidentiality, integrity, availability).
- Any known mitigations or workarounds.

## Response and Disclosure

- We will acknowledge new reports as quickly as possible.
- We will investigate, validate impact, and prioritize remediation.
- We follow coordinated disclosure and will publish details after a fix is available.
